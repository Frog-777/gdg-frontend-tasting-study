### 1주차 내용 요약

1. HTML : hyper text markup language
웹페이지에 무엇이 있는지 적는 언어
제목, 글, 이미지, 버튼이 있다는 것을 브라우저에게 알려주는 역할이에요

2. css : cascading style sheets
웹페이지에 **어떻게 보일지** 적는 언어
색상, 크기, 간격, 위치 등

3. js : Javascript
어떻게 동작하는지

+ 크롬에서 안녕하세요 추가하기
document.querySelector("h1").textContent = "안녕하세요!"
뜯어보면
querySelector("h1") : 화면에서 h1을 찾을게
.textContent = "안녕하세요!" : 안녕하세요로 바꿀게

-> 찾아서, 바꿈

+ DOM : document object model
Javascript는 DOM을 통해 웹페이지의 요소를 찾고 바꿀 수 있음

+ event : 행동
exㅣ 하트 누르는 행동 = event
